# Project brief

## Product intent
A music marketplace where independent artists can create and own their space, and listeners can discover and support them directly. Bandcamp is a product reference, not a specification to clone.

## Established direction
- Separate project and GitHub repository.
- Start with GitHub Pages for iteration.
- Borrow visual cues from Dirtyfreqs: strong type, editorial composition, black/off-white, orange accents.
- Artist identity and creative control are central.

## Current prototype
Discovery page, genre filtering, and fictional artist preview. No backend or commerce. Working name: Artist Marketplace.

## Next decisions with the founder
1. Final name and brand.
2. Artist page layout and customization controls.
3. First catalog: tracks, albums, beats, or a combination.
4. Purchase/download model and platform economics.
5. Artist signup, upload, and publishing experience.

## Additional artist mockup: M3TTA
- Route: `#/artist/m3tta`.
- Founder direction: simple, minimal, futuristic; supplied M3TTA Sessions artwork informs charcoal, white, red, and tightly set typography.
- Includes a real external Sessions #001 link. All storefront releases, products, prices, and bio copy are concept material.

## Suggested implementation sequence
1. Refine discovery and artist storefront designs.
2. Add release pages and licensed preview audio.
3. Choose authentication, database, and media storage.
4. Build artist editing/upload flows and define ownership/export controls.
5. Integrate payments, payouts, and protected downloads.

Keep commerce and infrastructure decisions open until requirements are confirmed.
